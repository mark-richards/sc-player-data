```

   YES → Draft them

   Use this tiebreaker order:
   a) Higher games played in 2025 (20+ wins)
   b) Better position (MID > RUC > DEF > FWD)

4. Is a GEM available 10+ spots below their ranking?
   → GRAB THEM (check gem list above)

5. Someone drafted a player you wanted?
   → Stay calm, next best available
   → Don't panic-reach
```
